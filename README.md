# 函数图绘制器

一个轻量级的函数图像绘制工具。单文件 HTML，双击即可在浏览器中打开使用。

## 功能

- 多曲线同时绘制，自动分配区分度高的颜色
- 滚轮缩放、拖拽平移，坐标范围输入框实时同步
- 网格与坐标轴刻度
- 鼠标悬停十字线坐标提示
- 明暗主题（跟随系统偏好自动切换）
- 响应式布局，窗口缩放自动适配

## 使用

直接双击 `index.html` 或在浏览器中打开即可。页面依赖 CDN（d3 + function-plot），需要网络连接。

## 支持的表达式

- 基础：`x^2`、`x^3`、`1/x`
- 三角函数：`sin(x)`、`cos(x)`、`tan(x)`
- 对数：`ln(x)`、`log(x)`、`log10(x)`、`log2(x)`
- 其他：`sqrt(x)`、`abs(x)`、`E^x`
- 欧拉常数用 `e` 或 `E`（如 `e^x`、`E^x`，小写 `e` 会自动转换为大写）
- 乘号可省略：`2x` 等价于 `2*x`

## 技术

- [function-plot](https://github.com/FunctionPlot/function-plot) 1.25.4（基于 d3）
- [d3](https://d3js.org/) 7.9.0
- 零构建工具、零 npm 依赖，全部内联在单个 HTML 文件中
